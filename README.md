# App de Gestión de Citas Médicas – Reporte Técnico

## 📑 Resumen
Este proyecto analiza y selecciona el stack de desarrollo para una aplicación móvil de gestión de citas médicas en Android e iOS.

## 🔧 Stack Comparado
- Flutter (Dart)
- React Native (Expo)
- Kotlin Multiplatform

## ✅ Stack Seleccionado
**Flutter + Dart** por su balance entre rendimiento, rapidez de desarrollo y soporte multiplataforma.

## 🖥️ Entorno de Desarrollo
- Android Studio (última versión) o VS Code con plugins Flutter/Dart.
- Configuración validada con `flutter doctor`.

## 📱 Hardware Requerido
- Cámara (QR)
- Notificaciones push
- Almacenamiento local
- GPS opcional
